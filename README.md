# student-performance-analysis
Student Performance Analysis using Python, Pandas, Excel, and Power BI to analyze students' academic performance, study habits, attendance, and other factors affecting results.
 Student Performance Analysis

This project analyzes student performance data to understand **academic results, study habits, attendance, and factors that may be associated with student performance**.

 Tools Used

* Python
* Pandas
* Matplotlib
* Excel
* Power BI

Analysis Areas

* Student marks and scores
* Average performance
* Attendance analysis
* Study hours
* Subject-wise performance
* Grade distribution
* Performance trends
* Relationship between study habits and academic results

 Project Objective

The objective of this project is to clean, analyze, and visualize student data to identify patterns in academic performance and present the findings through clear dashboards and visualizations.

 Skills Demonstrated

* Data Cleaning
* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Python & Pandas
* Data Visualization
* Excel Analysis
* Power BI Dashboard Development
* Data Insights
